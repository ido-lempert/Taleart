# TaleArt

Stories and promo banners for your own site or app. Self-hosted dashboard, API and Web SDK.

## What it does

You create a zone (a spot on your site), add a tale group with images, video or text, turn it on, and paste a snippet. The zone shows a stories bar or a promo banner.

## Quickstart

1. Set up TaleArt and name your project.
2. Create a zone: Stories bar, Promo banner or Blank.
3. Add a tale group with images or video.
4. Turn the group On.
5. Copy the snippet from the Install tab. Full steps: https://taleart.lempert.site/

## Requirements

Node.js 22 or later. A PostgreSQL database.

## Status

Web SDK is the main path. The Android and iOS SDKs have been reviewed in source but not tested on devices yet.
