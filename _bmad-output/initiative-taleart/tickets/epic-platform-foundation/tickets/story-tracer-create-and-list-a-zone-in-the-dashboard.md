# Tracer: create and list a zone in the dashboard

## Description

A user creates a project, then a zone in it, in the dashboard; both are stored in PostgreSQL through the API and are still listed after a restart.

## Requirements

Verify: Create a project and a zone in the dashboard, restart the API, reload: both are listed and the zone belongs to the project.
