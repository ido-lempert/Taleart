# Tag and audience targeting

## Description

Decides which groups a viewer sees, from tags combined with AND or OR and from audiences imported by CSV and matched to the external user key.

## Outcome

A team can target a tale group to a segment of viewers, and the viewer sees only the groups that match.

## Done when

- A test matrix over AND, OR and no-tag cases returns the expected groups.
- An audience CSV imports and matches the external user key.
