# The project dropdown shows only when there is more than one project

## Description

With one project the header has no dropdown; with two or more it appears as it does today. A new project is created only from the Projects page, which is where a one-project user goes.

## Requirements

Verify: An install with one project has no dropdown; the Projects page creates a second project and the dropdown then appears.
