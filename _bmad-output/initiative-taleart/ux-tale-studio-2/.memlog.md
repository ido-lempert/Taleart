topic: Tale Studio 2: low-code editor (palette, canvas, inspector)
updated: 2026-10-24T08:51
---


- (event) Owner request 2026-10-24: Storyly's studio feels more intuitive; make a better one with every component on the left to drag and drop and the selected element's properties on the right, like low-code apps. Run unattended; no questions; open decisions go to Owner decisions to confirm.
- (event) Inputs read: Storyly public docs (docs.storyly.io component, CTA, actions, creative, Canva pages), digest studio-r4-1.md, terminology-map.md, epic-tale-studio, epic-interactive-components, AD-15, AD-16, current tale-studio code (single right panel: Add button rows, Layers, Selected fields, Canvas fieldset; canvas left; preview toggled).
- (decision) Form factor: desktop-first responsive web in the existing Angular dashboard; tablet supported; phone is an edit-lite mode (tap to add, sheets), not full parity of pointer gestures.
- (decision) Layout: top bar, left panel, centre canvas, right inspector, bottom tale strip. Five landmark regions cycled with F6 / Shift+F6.
- (decision) Left panel has four tabs: Elements, Templates, Media, Layers. Elements is the default tab. [ASSUMPTION] Layers lives in the left panel like Figma and Canva; owner to confirm vs docking it under the inspector.
- (decision) Elements tab is generated from the element-type registry and each type's studio descriptor; descriptors gain palette metadata (category, keywords, presets, thumbnail). A registered type without palette metadata still shows, under More, with its label and icon. Test-only types never show.
- (decision) Palette categories, in order: Text, Media, Shapes, Stickers and emoji, Buttons and links, Interactive. Search filters across all categories by label and keywords and announces the result count.
- (decision) Add by drag (pointer) onto the canvas at the drop point, or by click / Enter / Space at the next free spot in the safe area. Both select the new element, move focus to it and announce it. Click-to-add is the WCAG 2.5.7 single-pointer alternative.
- (decision) Canvas: Fit zoom by default, 25 to 400 percent, Ctrl/Cmd plus, minus, 0 and 1, Ctrl+wheel and pinch, Space+drag or middle-drag to pan. Safe-area overlay toggle, on by default and shown strongly while dragging. Existing snapping kept; adds equal-spacing smart guides with distance labels.
- (decision) Multi-select by Shift/Cmd-click, marquee on empty canvas, Ctrl/Cmd+A, and Shift+Space in the layers list. With two or more selected the inspector shows Align (left, centre, right, top, middle, bottom) and Distribute; with one selected, align to canvas or safe area. Grouping elements is out of scope: the document has no group type.
- (decision) Tale strip: the group's tales as 9:16 thumbnails along the bottom, with add tale (blank, template, media), duplicate, reorder by drag with Move earlier/later buttons and Alt+Left/Right, a Shown/Hidden mark and a 'changes not updated' dot. Switching tales flushes autosave first.
- (decision) Inspector is contextual: nothing selected shows Tale settings (background, duration, fit); one element shows its sections; several show alignment plus the props they share. Sections, in order: Content, Style, Position and size, Animation, Action, Accessibility, Responses (interactive only). Sections are disclosure buttons; open state remembered per section.
- (decision) Low-code controls: colour swatches (project theme colours, colours in this tale, recent, custom with hex), slider paired with a number field, segmented control as a radio group, font picker as a combobox listing each font in its own face (project fonts, theme font, system stacks, upload font inline), toggle switches, emoji picker kept.
- (decision) Descriptor fields gain a section and the controls slider, segmented, swatch, toggle and font, so a future type gets low-code controls from configuration alone. Default section is Content.
- (decision) Animation: an optional per-element entrance (none, fade, slide up, slide from start, pop, drift) with delay and duration, as an additive optional field per AD-15. SDK plays it once, skips it under prefers-reduced-motion. [ASSUMPTION] needs architect sign-off and SDK budget check.
- (decision) Templates tab: built-in whole-tale starter templates (from libs/contract registry) and element presets (text styles, button styles). Applying a whole-tale template to a non-empty tale asks to replace or add as a new tale; one undo step. Project-saved templates are a later story.
- (decision) Media tab: the project's media library with search, filter (images, videos, stickers) and upload by button or by dropping files on the panel or the canvas. Drag media onto the canvas adds an image or video element; dropping on the Background target sets the tale background.
- (decision) Top bar: back to group, tale name, undo/redo, zoom control, safe-area toggle, Preview, save state, status line and Update tale (primary). Discard changes and Duplicate move to a tale menu.
- (decision) Preview: the real Web SDK viewer (AD-16) in a phone frame, switchable sizes, a Right-to-left host check, play from start; opens as a pane replacing the inspector on wide screens and as a dialog on narrow ones.
- (decision) [ASSUMPTION] Canvas draws configured element types (poll, rating, quiz and later) with the SDK document renderer, so the canvas matches the site; studio handles and outlines draw over it. Needs architect check; fallback is today's stand-in text.
- (decision) RTL: text direction per element kept (auto, LTR, RTL); alignment as start and end; a 'Mirror for right-to-left' tale action that flips x positions and sets text direction, one undo step; preview checks RTL. Studio UI itself stays English LTR.
- (decision) Shapes: add star, arrow and speech bubble kinds and a stroke (colour, width) to the shape type; rectangle corner radius slider. [ASSUMPTION] additive enum change per AD-15.
- (decision) Responsive: 1280px and up: all regions. 1024 to 1279: left panel collapses to an icon rail with a flyout. 768 to 1023: inspector becomes a right drawer opened by selection or a Properties button. Below 768: canvas full width with a bottom toolbar (Add, Layers, Properties, Tales) opening sheets; tap to add; no palette drag.
- (decision) Accessibility floor is WCAG 2.2 AA: every drag has a keyboard and single-pointer path (2.1.1, 2.5.7); focus not obscured by sticky bars or sheets (2.4.11); targets at least 24px (2.5.8); one polite live region announces add, move (debounced), align, delete, undo and save failures; palette items are buttons in labelled groups; layers list keeps its existing keyboard model.
- (decision) Undo/redo, autosave, conflict flow and Update tale keep today's AD-15 semantics; a multi-element operation (align, distribute, template apply, mirror) is one undo step named for the action.
- (decision) Beat Storyly on: font picker with project fonts, shapes with stroke, layers with lock/hide/reorder, alignment and distribution, accessibility (alt text per element, contrast, reading order, keyboard parity), live preview of the real SDK, RTL, animation, templates. Never copy Storyly text or assets.
- (assumption) Owner reviews the new layout on a clickable shell before the inspector and palette are rebuilt (hitl design review early in epic 11).
