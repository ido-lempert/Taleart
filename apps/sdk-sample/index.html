TaleArt Web SDK sample

A host page for trying the SDK. Open it as ?zones=<slug>,<slug>&api=<API URL>#siteKey=<site key> to place one element per zone slug with the project's site key, each under its own heading; the API URL defaults to http://localhost:3333. Each element shows its zone's display, a bar or a banner. Keys go in the fragment (after #), which the browser never sends to a server or in a Referer header; the query still works.

Add &theme=<JSON> to override the project's theme in the SDK configuration, for example &theme={"ringStyle":"solid","ringColors":["#0000ff"]}. The page passes it to configureZone(zone, { theme }) for every zone, or only for the slug named by &themeZone=<slug>; a field set there wins over the project's theme, and an invalid one is ignored with a console warning. One element can also take its own theme property or JSON attribute, which wins over the zone's. See the web-sdk README for every field.

Add &tags=summer,vip to pass the viewer's targeting tags with setTags(tags), or set them below: each element then shows only the tale groups whose tags match (Any or All, set in the group's Audience), and every group without tags. Without tags, every group shows.

No viewer tags: every group shows.
