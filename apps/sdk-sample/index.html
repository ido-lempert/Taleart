TaleArt Web SDK sample

A host page for trying the SDK. Open it as ?key=<zone key>&api=<API URL>; the API URL defaults to http://localhost:3333. The element shows the zone's display, a bar or a banner.

Add &theme=<JSON> to override the project's theme for the zone in the SDK configuration, for example &theme={"ringStyle":"solid","ringColors":["#0000ff"]}. The page passes it to configureZone(key, { theme }); a field set there wins over the project's theme, and an invalid one is ignored with a console warning. One element can also take its own theme property or JSON attribute, which wins over the zone's. See the web-sdk README for every field.
