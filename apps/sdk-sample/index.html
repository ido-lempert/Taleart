TaleArt Web SDK sample

A host page for trying the SDK. Open it as ?siteKey=<site key>&zones=<slug>,<slug>&api=<API URL> to place one element per zone slug with the project's site key, each under its own heading; the API URL defaults to http://localhost:3333. Each element shows its zone's display, a bar or a banner. A legacy zone key still works: ?key=<zone key> places one zone, ?keys=<key>,<key> one element per key.

Add &theme=<JSON> to override the project's theme in the SDK configuration, for example &theme={"ringStyle":"solid","ringColors":["#0000ff"]}. The page passes it to configureZone(zone, { theme }) for every zone, or only for the slug (or key) named by &themeZone=<slug>; a field set there wins over the project's theme, and an invalid one is ignored with a console warning. One element can also take its own theme property or JSON attribute, which wins over the zone's. See the web-sdk README for every field.
