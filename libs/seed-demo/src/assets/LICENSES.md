# Demo pictures

Every picture in this folder is original artwork made for the TaleArt repository. Nothing was
downloaded or taken from a photo library, a stock site or a model's training set of third-party images:
the flat furniture scenes are drawn as SVG by `libs/seed-demo/scripts/render-assets.mjs` and rendered
to JPEG (quality 80) with Chromium. Run that script from the repository root to redraw them.

Author: the TaleArt authors. Licence: Apache-2.0, as the rest of the repository (`LICENSE`). The
furniture, brand and product names in the demo (Nordic Home, Fjord, Lumi, Aura, Tuva) are made up; the
pictures show no real product, logo or person.
